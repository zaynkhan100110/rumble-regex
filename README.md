


## What is it ?

This a rumble regex script what i build for my <a href="https://github.com/zaynkhan100110/ump">ump</a> project

## What the work of it ?

While downloading a rumble content you will found that the url you see on browser tab or from share button those url cannot be used for download. Rumble server server another url from their server that linked their actual stream file. So after inspection i made this automated tool that will go and look for server url with  id and give it to you

## How does it work (How can this script talks to the server) ?

This automated scripts use playwright (a browserlike application and send requests to the rumble server to get the link)

## Notice :::

Rumble actively change their regex so keep update. Also private video may not be unreachable with this script
